# bookshelf portfolio

sanyam's portfolio: a bookshelf where each book is a place i've worked.

- throw the books around, or click one to open it
- the keyboard warrior sticker opens a wall of linkedin comments
- stay 45 seconds and see what the ball does

one file, `index.html`. open it in a browser, no build step. uses [matter.js](https://brm.io/matter-js/) from cdnjs for the physics.
